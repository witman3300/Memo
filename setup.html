📌 구글 드라이브 연결

메모를 내 구글 드라이브의 MemoWidget/content.txt 에 저장해, PC 위젯과 휴대폰 웹앱이 같은 메모를 함께 씁니다.

상태 확인 중…
  1. Google Cloud Console 에서 프로젝트를 하나 만듭니다.
  2. API 및 서비스 → 라이브러리 → Google Drive API 사용 설정
  3. OAuth 동의 화면 → 외부 → 테스트 사용자에 본인 구글 계정 추가
  4. 사용자 인증 정보 → 클라이언트 ID 만들기 → 유형 데스크톱 앱
  5. 발급된 클라이언트 ID / 시크릿을 아래에 붙여넣고 [연결하기]
