# 📌 메모위젯 (Desktop Memo Widget)

바탕화면 왼쪽에 고정되는 **반투명 메모 위젯**입니다. 메모·할 일 체크리스트·시간대별 일정을 한 곳에서 관리하고, 카카오톡으로 바로 보낼 수 있습니다. Electron 기반으로 단일 `.exe`(portable)로 빌드됩니다.

## ✨ 기능

- **반투명 프레임리스 위젯** — 화면 왼쪽 끝에 고정, 바탕화면이 비치는 유리 느낌
- **보기 / 편집 토글** — 더블클릭으로 편집, 바깥 클릭으로 보기 복귀 (저장 버튼 없음)
- **자동 저장** — 입력 즉시 로컬 파일에 저장, 다시 켜도 유지
- **상단 일정 체크리스트** — `🔲 / ✅` 항목을 클릭해 완료 토글 (완료 시 취소선)
- **시간 줄 자동 변환** — `09:30 …` 처럼 시간으로 시작하는 줄에 자동으로 체크박스 부여
- **자동 번호 매기기** — 구분선(`----`/`====`) 구획별로 `1, 2, 3 …` 오름차순 정렬
- **줄 이동** — 편집 중 `Alt + ↑ / ↓` 로 현재 줄(또는 선택 줄들) 위아래 이동
- **되돌리기 / 새로고침** — 상단 바 버튼 (↶ 되돌리기 · ↻ 새로고침)
  - 새로고침: 번호 없는 줄에 번호 부여, 내용 없는 번호 줄 제거
- **카카오톡 전송 (💬)** — 메모를 클립보드에 복사하고 카카오톡을 열어 '나와의 채팅'에 붙여넣기

## 🖱️ 사용법

| 동작 | 방법 |
|---|---|
| 편집 시작 | 메모 영역 **더블클릭** |
| 저장 / 보기 복귀 | 메모 **바깥 클릭** (자동 저장) |
| 항목 완료 토글 | 상단 일정의 **체크박스 클릭** |
| 줄 위/아래 이동 | 편집 중 **`Alt + ↑` / `Alt + ↓`** |
| 창 이동 | 상단 바 **📌 드래그** |
| 되돌리기 | 상단 **↶** |
| 새로고침(번호 정리) | 상단 **↻** |
| 카톡으로 보내기 | 상단 **💬** → 카톡에서 `Ctrl + V` |
| 닫기 | 상단 **×** |

## 🚀 실행 (배포본)

빌드된 `MemoWidget.exe`(portable) 하나만 있으면 설치 없이 실행됩니다. 다른 PC로 옮겨도 그대로 동작합니다.

> 미서명 앱이라 처음 더블클릭 시 SmartScreen 파란 경고가 뜰 수 있습니다 → **"추가 정보" → "실행"**. (자동실행/바로가기로 켜질 땐 경고가 없습니다.)

### 부팅 시 자동 실행
시작프로그램 폴더(`Win + R` → `shell:startup`)에 `MemoWidget.exe` 바로가기를 넣으면 됩니다.

## 🛠️ 개발 / 빌드

```bash
npm install        # 의존성 설치
npm start          # 개발 모드 실행
npm run dist       # portable .exe 빌드 → dist/MemoWidget.exe
```

## 💾 데이터 저장 위치

```
%APPDATA%\desktop-memo\content.txt
```

메모 본문은 위 파일에 저장되며, 저장소(git)에는 포함되지 않습니다.

## 📁 구성

| 파일 | 역할 |
|---|---|
| `main.js` | Electron 메인 프로세스 (창 생성, 파일 입출력, 카톡 실행) |
| `preload.js` | 렌더러에 안전한 API 노출 (contextBridge) |
| `index.html` | 위젯 UI / 스타일 |
| `renderer.js` | 메모 로직 (렌더링, 체크박스, 번호, 줄이동, 되돌리기 등) |
| `icon.ico` | 앱 아이콘 |
| `package.json` | electron-builder 빌드 설정 |

## 🧰 기술 스택

- [Electron](https://www.electronjs.org/)
- [electron-builder](https://www.electron.build/) (portable target)
